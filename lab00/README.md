# Лабораторная работа №0 — основы Arduino Uno

Номер взят из имени исходного файла `Лабораторная работа №0 для начинающих`. Внутренний заголовок PDF ошибочно называет её лабораторной №1.

**Материалы:** [отчёт](report.pdf) · [демонстрационное видео](demo.mp4) · [контрольные вопросы](questions.md) · [исходники](src/) · [схемы Wokwi](circuits/)

## Что реализовано

| Пункт | Проект | Результат |
|---:|---|---|
| 1 | `task01_builtin_blink` | мигание встроенного LED D13 |
| 2 | `task02_external_led` | внешний красный LED D13 через 220 Ом |
| 3 | `task03_button_hold` | LED горит только при удержании кнопки D2 |
| 4 | `task04_button_toggle` | каждое подтверждённое нажатие переключает LED; антидребезг 40 мс |
| 5 | `task05_pot_brightness` | потенциометр A0 управляет PWM-яркостью LED D3 |
| 6 | `task06_brightness_lock` | при удержании кнопки яркость фиксируется, изменение потенциометра отклоняется |
| 7А | `task07a_traffic_delay` | светофор с последовательными задержками |
| 7Б | `task07b_traffic_for` | светофор с циклами `for` и обратным отсчётом в Serial |
| 8 | `task08_button_traffic` | цикл светофора запускается кнопкой после обязательной задержки 5 секунд |
| 9 | `task09_rgb_traffic` | светофор на RGB LED, жёлтый получается смешением красного и зелёного |
| 10 | `task10_rgb_palette` | потенциометр плавно проходит цветовой круг из рисунка методички |

Пункт 11 с энкодером отмечен звёздочкой и является дополнительным, поэтому в обязательный комплект не включён.

## Подключение

- D2 — кнопка, используется внутренний `INPUT_PULLUP`, нажатие замыкает вход на GND.
- D3 — PWM-выход обычного LED в заданиях 5–6.
- D3, D4, D5 — красный, жёлтый и зелёный сигналы обычного светофора.
- D9, D10, D11 — каналы R, G, B RGB-светодиода.
- A0 — средний вывод потенциометра; крайние выводы соединены с 5V и GND.
- Каждый внешний канал LED подключён через отдельный резистор 220 Ом.

В заданиях 5–6 применён D3 вместо указанного в предыдущей схеме D13. На Arduino Uno вывод D13 не поддерживает аппаратный PWM, поэтому он не может корректно выполнять обычное регулирование яркости через `analogWrite()`.

## Сборка

Каждый каталог внутри `src` является отдельным Arduino-скетчем. Пример:

```powershell
arduino-cli compile --fqbn arduino:avr:uno --output-dir build/lab00/task06_brightness_lock lab00/src/task06_brightness_lock
```

Соответствующие `diagram.json` и `wokwi.toml` расположены в `circuits`.

## Визуальная демонстрация

Файл `open-wokwi.cmd` собирает задание 6, открывает его схему в VS Code и вызывает команду запуска Wokwi. На демонстрации:

1. поверните потенциометр и покажите изменение яркости;
2. удерживайте синюю кнопку `LOCK`;
3. снова поверните потенциометр — яркость не должна измениться, в Serial появится `T06:CHANGE_IMPOSSIBLE`;
4. отпустите кнопку и снова поверните потенциометр — управление яркостью восстановится;
5. остановите симуляцию сразу после записи.
