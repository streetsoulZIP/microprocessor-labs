# Lab01 — работа с портами микроконтроллера и битами

Готовая реализация для Arduino Uno / ATmega328P. Основной скетч: `ports/ports.ino`.

## Подключение

| Устройство | Пин Uno | Порт AVR |
|---|---:|---|
| Кнопки | D2, D3, D4 | PD2, PD3, PD4 |
| Светодиоды | D11, D12, D13 | PB3, PB4, PB5 |

Кнопки замыкают пин на GND, используется внутренняя подтяжка. Светодиоды в физической схеме подключаются через резисторы 220 Ом. Карта PB0=D8 … PB5=D13 соответствует реальному Uno и исправляет ошибку таблицы методички.

## Запуск

В корне проекта:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\build.ps1 -Lab lab01 -Sketch ports
.\scripts\test.ps1 -Lab lab01
```

Для визуальной симуляции откройте папку `ports` в VS Code, выберите `ports/wokwi.toml` в **Wokwi: Select Config File**, затем выполните **Wokwi: Start Simulator**. Нужны ранее активированное расширение/лицензия Wokwi для VS Code; CLI-проверки используют отдельный токен из окружения.

## Результаты

- Сборка Uno: 2712 Б Flash (8%), 199 Б SRAM (9%).
- Реальная Wokwi-симуляция подтверждает нулевую маску, D2 и одновременные D3+D4 (`POS=[1,2]`).
- Проверка debounce: 10-мс импульс отклонён, устойчивое нажатие принято.
- Временные метки 200, 400, 600, 800 мс подтверждают частоту обновления 5 Гц.
