# Лабораторные работы по программированию микропроцессоров

**Самарский государственный технический университет**<br>
Дисциплина: «Программирование микропроцессоров»<br>
Автор:  Яковенко Богдан Елисеевич, 3-110-ИАИТ

Комплект материалов для сдачи лабораторных работ на Arduino Uno / ATmega328P: отчёты, демонстрации, исходные тексты и интерактивные схемы Wokwi.

Номер каждой работы соответствует имени исходного PDF (`№0`, `N1`, `N2`, `N3`), даже если номер на титульной странице самого документа отличается. Ниже перечислены четыре самостоятельных комплекта для сдачи.

| Работа | Результат | Материалы |
|---|---|---|
| [ЛР №0](lab00/) — основы Arduino | Одиннадцать отдельных проектов: LED, кнопки, потенциометр, PWM, два светофора и RGB; подтверждены сборкой и Wokwi. | [Отчёт](lab00/report.pdf) · [Видео](lab00/demo.mp4) · [Код](lab00/src/) · [Вопросы](lab00/questions.md) |
| [ЛР №1](lab01/) — порты и биты | Три кнопки управляют тремя LED через регистры AVR; подтверждены антидребезг, одновременное нажатие и обновление 5 Гц. | [Отчёт](lab01/report.pdf) · [Видео](lab01/demo.mp4) · [Код](lab01/src/ports/ports.ino) · [Вопросы](lab01/questions.md) |
| [ЛР №2](lab02/) — конечный автомат | Светофор реализован через `switch-case` и таблицу обработчиков; приведено сравнение Flash/SRAM. | [Отчёт](lab02/report.pdf) · [switch-видео](lab02/switch-demo.mp4) · [table-видео](lab02/table-demo.mp4) · [Код](lab02/src/) · [Вопросы](lab02/questions.md) |
| [ЛР №3](lab03/) — прерывания | INT0, Timer0 и Timer1 применены для LED, клавиатуры 4×4 и LCD; четыре сценария подтверждены Wokwi CLI. | [Отчёт](lab03/report.pdf) · [Видео](lab03/media/lab03-demo.mp4) · [Код](lab03/src/) · [Вопросы](lab03/questions.md) |

Ключевые результаты проверены компиляцией Arduino CLI и симуляцией Wokwi. Работа выполнена в симуляторе; физическая плата Arduino Uno не использовалась.
