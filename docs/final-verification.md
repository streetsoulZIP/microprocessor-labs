## Изменения аудита

- `lab02` отформатирован для чтения и защиты, но алгоритм, пины, протокол Serial и размеры прошивки не изменены.
- Статический тест `FsmTests.ps1` теперь принимает допустимые пробелы в объявлении `DEBOUNCE = 50`, а не зависит от форматирования строки.
- Добавлены PDF/DOCX-отчёты, корневой README, ссылки на три сохранённых видео и эта сводка.
- Для публикации создан локальный Git-коммит `5c53b14` на ветке `main`. Видео сохранены без перекодирования: lab01 — 9,32 МиБ, lab02 switch — 31,64 МиБ, lab02 table — 20,65 МиБ; все меньше лимита GitHub 100 МиБ на файл.

## Ограничения

- Физическая Arduino Uno не использовалась: аппаратное поведение проверено Wokwi.
- В ped/debounce-сценариях lab02 журнал содержит ожидаемую очередь и продление красного, но Wokwi runner завершился кодом `timeout 42` уже после записи лога. Поэтому этот прогон не обозначается успешным автоматическим сценарием.
- Полный PDF-визуальный контроль выполнен. DOCX открываемы и редактируемы, но автоматическая растеризация DOCX не была доступна из-за отсутствия LibreOffice на машине.
- Публикация на GitHub ожидает повторной авторизации `gh`: текущий токен аккаунта `streetsoulZIP` недействителен. Секреты в проект не добавлялись.
