# Лабораторная работа №4 — изучение методов индикации

[Отчёт PDF](report.pdf) · [Видео 1](media/task1-tft-demo.mp4) · [Видео 2](media/task2-sevenseg-timer-demo.mp4) · [Видео 3](media/task3-sevenseg-595-demo.mp4) · [Видео 4](media/task4-matrix-animation-demo.mp4) · [Видео 5](media/task5-matrix-scroll-demo.mp4) · [Видео 6](media/task6-lcd-status-demo.mp4) · [Исходный код](src/) · [Схемы Wokwi](circuits/) · [Ответы на вопросы](questions.md)

## Что реализовано

1. TFT ILI9341 320×240: графическая панель, выбор красного, зелёного и синего цвета, рисование касанием.
2. Четырёхразрядный семисегментный индикатор: измерение напряжения A0, мультиплексирование по Timer1 с частотой 250 Гц на разряд.
3. Вариант индикатора через два каскадных 74HC595: три управляющие линии Arduino и обновление каждого разряда с частотой 125 Гц.
4. Одна матрица 8×8 с MAX7219: статический рисунок и анимация из четырёх кадров.
5. Четыре матрицы MAX7219: 32-столбцовый буфер и бегущая строка `SAMGTU`.
6. LCD 16×2 по I2C: напряжение, ADC и состояния `LOW`, `NORMAL`, `HIGH`.

Каждое задание имеет собственные скетч, `diagram.json`, `wokwi.toml`, HEX и ELF после сборки.

## Реальная проверка

| Задание | Flash / SRAM | Подтверждённый результат Wokwi |
|---|---:|---|
| TFT + touch | 15 658 Б / 572 Б | кнопка RED и точки (60,70), (260,190); снимок сохранён |
| 4×7-seg + Timer1 | 2 910 Б / 227 Б | 2,502 В → 4,003 В; 250 Гц на разряд |
| 4×7-seg + 74HC595 | 2 572 Б / 209 Б | счёт 0001 → 0002; 125 Гц на разряд |
| MAX7219 8×8 | 2 296 Б / 193 Б | статический X и кадры 1–3 |
| 4×MAX7219 | 2 876 Б / 226 Б | бегущая строка прошла смещения 0 и 8 |
| LCD 16×2 | 4 996 Б / 440 Б | `NORMAL` → `LOW` → `HIGH` |

Все шесть сценариев Wokwi CLI завершились сообщением `Scenario completed successfully`. Логи и тестовые сценарии хранятся локально; в публичный комплект не добавлены, чтобы репозиторий оставался простым.

## Сборка

Из корня репозитория, подставив имя задания:

```powershell
arduino-cli compile --fqbn arduino:avr:uno --output-dir build/lab04/task1_tft_touch lab04/src/task1_tft_touch
```

Имена папок: `task1_tft_touch`, `task2_sevenseg_timer`, `task3_sevenseg_595`, `task4_matrix_animation`, `task5_matrix_scroll`, `task6_lcd_status`.

## Запуск Wokwi для демонстрации

Откройте соответствующую папку из `lab04/circuits` в VS Code и выполните команду **Wokwi: Start Simulator**. Файлы `diagram.json`, `wokwi.toml`, HEX и ELF уже связаны между собой. Локальные однокнопочные файлы запуска сохранены на настроенном компьютере, но в репозиторий не публикуются.

## Обоснованные отклонения от методички

- В симуляторе Wokwi ILI9341 имеет ёмкостный контроллер FT6206, поэтому он заменяет указанный в методичке резистивный XPT2046. Рисование касанием сохраняется, а аппаратная калибровка XPT2046 описана в ответах.
- В физической прямой схеме нужны восемь резисторов 220 Ом и четыре транзисторных ключа разрядов. Цифровая модель Wokwi допускает прямое соединение; расчёт резисторов и физическая схема приведены в отчёте.
- Порядок работы упоминает два варианта 4×7-seg, хотя детализированный раздел раскрывает только один. Реализованы оба: прямой и через 74HC595.
